# Portafolio de Prácticas - Lenguajes de Interfaz (Unidad 3)

En este repositorio se presentan las prácticas desarrolladas durante la **Unidad 3** de la materia **Lenguajes de Interfaz**. Los programas abarcan el funcionamiento del puntero de instrucción (`EIP`), validación de cadenas de entrada, manipulación y suma de datos mediante la pila del sistema, y la automatización de código utilizando **macros** en lenguaje ensamblador (MASM / Irvine32).
